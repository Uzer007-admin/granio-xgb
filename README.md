# X11 для Granio

Протокол X11 и вспомогательные пакеты в одном Go-модуле.

**Основной исходник:** https://github.com/fyne-io/xgb.
**Дополнительный исходник:** https://github.com/fyne-io/xgbutil.
**Цель форка:** совместное сопровождение протокола, EWMH, ICCCM,
обработки событий, клавиатуры и X11-графики для Granio.
Истории Git, лицензии и сведения об авторах сохранены.
Реестр источников — [SOURCES.json](SOURCES.json).

Протокол доступен по `github.com/Uzer007-admin/granio-xgb`;
вспомогательные пакеты — по `github.com/Uzer007-admin/granio-xgb/xgbutil`.
Старый префикс `granio-xgbutil` заменяется на этот путь с сохранением подкаталогов.
Минимальная версия Go — 1.27.1.

```sh
go get github.com/Uzer007-admin/granio-xgb@418fa8a142d85fb7f067f5e625c40c138ac1ed3e
go test ./...
```

Тесты, открывающие X11-соединение, требуют работающий X-сервер;
для автоматических проверок используется Xvfb.
[Материалы исходного проекта](UPSTREAM.md).
